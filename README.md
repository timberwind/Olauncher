# Clean Launcher
- I took Tanuj's excellent minimalistic OLauncher and hacked on it a bit to resolve a few peeves of mine. Probably not ideal for anyone else's use in particular.

  - app menus feature

  - removed various annoying popups and links in settings

  - removed wallpaper feature as well

  - fixed bug when turning off the screen time display

- to install: clone the repo and then ask Claude Code to build and install it for you
